# scanner-dtt

Dott QR Plate Generator: scan QR plates, number plates or a batch of scooter QR codes, then print, export or share the list.

For Dott internal operations only. Do not share these links outside the team.

## Install

**iPhone / iPad**

1. Open https://zxc0x-dmz.github.io/dott-qr-generator/ in **Safari**.
2. Tap **Share**, then **Add to Home Screen**.
3. Open **Dott QR** from the home screen. It updates by itself when you are online.

**Android**

- **App (APK):** download https://zxc0x-dmz.github.io/dott-qr-generator/Dott-QR-Generator.apk and open it. If Android asks, allow installing from this source. To update, install the newer APK over the old one.
- **Or the web app:** open https://zxc0x-dmz.github.io/dott-qr-generator/ in **Chrome** and choose **Add to Home screen** / **Install app**.

The camera needs the https link above; it does not work when `index.html` is opened as a file.

Current version: **1.73**
